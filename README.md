# Sua Técnica no Pódio — Maria Lisboa

Landing page da mentoria presencial de extensão de cílios da Maria Lisboa, reproduzida a partir do frame **SUA TECNICA NO PODIO** no Figma.

## Executar localmente

Requisitos: Node.js 22.13 ou mais recente.

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Gerar a versão de produção

```bash
npm run build
```

O projeto está pronto para versionamento no GitHub e publicação em plataformas compatíveis com aplicações Vite/Cloudflare Workers.
